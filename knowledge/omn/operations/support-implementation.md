# Oman Support & Implementation

## Support

- Functional / enterprise support **24×7×365** available under SLA
- MENA-based support centre model for regional customers
- Support during performance testing and security testing as part of implementation
- Service monitoring and operational health-check procedures documented for deployments
- Post-go-live integration support and knowledge transfer to the customer technical team

## Implementation

- Typical bank-scale Oman e-invoicing implementation timeline: **6–8 weeks** (scope-dependent)
- Resource mobilisation within commercially agreed timelines after contract signing
- Training approach for business and admin users provided as part of delivery
- Detailed project plan and implementation methodology included in technical proposals
- Stabilization phase after go-live is commonly scoped (e.g. ~3 months) when required by the customer contract — confirm per engagement

## Releases & upgrades

- Major release frequency: approximately every **3–6 months**
- Continuous upgrade of the platform with minimum downtime design
- Change management / code release control supported
- Single code base for the application platform (not multiple native code bases per channel)

## Documentation delivered with the solution

- User manual, administration manual, troubleshooting guide, installation documentation
- Operating manuals for usage, administration, and operations
- Instructions for maintenance, log retention, capacity, health checks, start-up/shutdown
- Exception-handling instructions for operational events
- Technical documentation for the solution and partner components where applicable
- Restore procedure and DR installation details provided for the engagement
- Source code escrow with an independent third party can be supported when contractually required

## Delivery methodology

- Agile delivery is supported; waterfall can be accommodated when the customer prefers it
- UAT support, training, and post-implementation support included in standard delivery posture
