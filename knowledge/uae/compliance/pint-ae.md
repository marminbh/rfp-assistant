# PINT-AE & Peppol Regulatory Updates

Marmin continuously monitors regulatory and industry standards to maintain UAE e-invoicing compliance.

## Standards covered in the release lifecycle

- PINT specification upgrades
- Peppol BIS updates
- UAE e-Invoicing framework updates
- XML Schema revisions
- Validation rule updates
- Code list updates

All regulatory changes follow the same controlled promotion and validation process (Development → Sandbox → White-labelled Sandbox → Production) before production deployment.

Sandbox validation includes PINT XML validation and PEPPOL interoperability testing.
